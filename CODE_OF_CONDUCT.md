# Code of Conduct

We want this project to be a friendly place for everyone.

- Be respectful and kind. Assume good intent.
- No harassment, discrimination, personal attacks or trolling.
- Critique code and ideas, not people.
- Help newcomers, including people driving AI agents.

Maintainers may remove comments, commits or contributors that violate these rules.
Report problems privately to the maintainers (see [SECURITY.md](SECURITY.md) for contact options).
