# Security Policy

Voice Meter accesses the microphone. It computes a loudness level in memory and **never records, stores or transmits
audio**. It makes no network connections.

If you find a vulnerability or any behavior that contradicts the above, please **do not open a public issue**. Report it
privately via GitHub's *Security → Report a vulnerability* (private vulnerability reporting) on this repository.
We aim to respond within 7 days.
